# 测试说明

后端测试位于 backend/src/test，覆盖权限、输入校验、排课、请假补课和头像。运行 `mvn -f backend/pom.xml test`，单元回归不需要现有业务数据库。

前端运行 `npm ci` 后执行 `npm run build`。本仓库不包含作者服务器的验收日志、文件 ID、上传对象、签名 URL 或数据库备份。

## 隔离 API 回归

Python 3.10+ 直接运行 scripts/integration-test.py 和 audit-*.py。它们会创建或更改测试业务数据，只能用于独立的测试库和测试后端，不能用于生产服务器或日常演示库。

1. 手工创建独立数据库 studio_test 并授予测试账号建表和增删改查权限。
2. 启动另一个后端实例：dev profile，数据库 URL 指向 studio_test，SERVER_PORT=18081，STORAGE_PROVIDER=local，STORAGE_LOCAL_PATH 指向独立的测试目录。不要配置真实 OSS 密钥。
3. 等待测试后端健康接口返回 UP。脚本默认请求 http://127.0.0.1:18081/api。
4. 按需运行脚本。integration-test.py 会写入并保留测试夹具；audit-home-test.py 依据当前数据校验首页聚合。需要可重复的初始状态时，应由操作者重新创建已确认可丢弃的测试库，而不是清空真实业务库。

```bash
python scripts/integration-test.py
python scripts/audit-access-test.py
python scripts/audit-schedule-test.py
python scripts/audit-leave-test.py
python scripts/audit-input-test.py
python scripts/audit-home-test.py
```

这些脚本是开发回归工具，生成结果位于忽略提交的 work/ 或 docs/test-evidence/。空目录可按需创建。不将历史部署通过数当作本机新环境的测试结果，实际结果以运行输出为准。
